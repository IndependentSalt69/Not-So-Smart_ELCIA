# CivicPulse Evidence Media Serving & Storage Integration

**Document Date:** August 24, 2026  
**System Area:** ML Pipeline Evidence Storage & Static Media Serving  

---

## 1. Evidence Storage Location

Physical evidence frames and visual hazard snapshots generated by `HazardVideoPipeline` (`src/detection/video_tracker.py`) are saved locally to:

```text
outputs/evidence/
  ├── hazard_1_LOW.jpg
  ├── hazard_2_LOW.jpg
  ├── hazard_3_LOW.jpg
  └── ...
```

The database schema (`src/db/models/evidence.py`) stores relative paths in `evidence.file_path`:
```sql
outputs/evidence/hazard_3_LOW.jpg
```
This ensures database portability across environments without hardcoding hostnames, IP addresses, or local operating system drive letters.

---

## 2. Public / Internal URL Mapping

FastAPI serves the evidence directory via Starlette's `StaticFiles` mounted at `/static/evidence`:

```python
# src/api/main.py
os.makedirs(settings.EVIDENCE_DIR, exist_ok=True)
app.mount(
    "/static/evidence",
    StaticFiles(directory=settings.EVIDENCE_DIR),
    name="static_evidence",
)
```

### URL Resolution Example
| Relative Storage Path | Public HTTP Media URL |
| :--- | :--- |
| `outputs/evidence/hazard_3_LOW.jpg` | `http://127.0.0.1:8000/static/evidence/hazard_3_LOW.jpg` |
| `outputs/evidence/hazard_1003_LOW.jpg` | `http://127.0.0.1:8000/static/evidence/hazard_1003_LOW.jpg` |
| `https://s3.amazonaws.com/bucket/img.jpg` | `https://s3.amazonaws.com/bucket/img.jpg` (Direct passthrough) |

## 3. Security Constraints & Path Traversal Prevention

1. **Restricted Directory Scope**:
   Only `outputs/evidence/` is exposed under `/static/evidence`. Project source code (`src/`), model weights (`models/`), raw drone videos (`data_raw/`), and test folders are unmounted and return `404 Not Found`.

2. **Path Traversal Rejection**:
   Attempts to escape the media directory via relative parent traversals (`../`, `..%2f`, etc.) are intercepted and rejected by Starlette's `StaticFiles` security validation layer with `404` / `400` status codes.

3. **Relative Database Storage**:
   The database never stores arbitrary absolute system paths (e.g. `C:\Windows\...` or `/etc/...`), ensuring clean isolation between client-side media requests and host filesystem structures.

## 4. Frontend Consumption

The React frontend handles media URL conversion centrally in `dashboard/client/src/services/incidentService.ts`:

```ts
export function getEvidenceMediaUrl(filePath?: string | null): string {
  if (!filePath) return '';
  if (filePath.startsWith('http://') || filePath.startsWith('https://') || filePath.startsWith('data:')) {
    return filePath;
  }
  const cleanFilename = filePath.replace(/^.*[\\\/]/, '');
  if (!cleanFilename) return '';

  const origin = getMediaBaseUrl();
  return `${origin}/static/evidence/${cleanFilename}`;
}
```

In `EvidenceViewer.tsx`, the component prefers the real `mediaUrl` when rendering the visual drone capture canvas:
- Success State: Renders the real drone snapshot with a green `"REAL EVIDENCE CAPTURE"` badge.
- Loading State: Shows animated radar indicator while querying `/incidents/{id}/evidence`.

---

## 5. Fallback Behavior

If an evidence asset is missing from disk, or if the media URL returns an HTTP error (404/500), `EvidenceViewer.tsx` implements non-blocking fallback handling:

1. **Error Interception**: The `<img>` element's `onError` callback flips `imageLoadError = true`.
2. **SVG Simulation Fallback**: The canvas instantly falls back to the high-contrast synthetic SVG visualization (`incident.evidenceFrame` / `incident.evidenceOverlay`).
3. **User Feedback**: A discreet yellow `"PREVIEW FALLBACK"` badge is displayed in the upper-right corner.
4. **No Infinite Retries**: The component does not continuously spam the backend for missing images, maintaining smooth UI performance.

## 6. Future S3 / Object Storage Migration Path

For multi-node cloud deployments (Kubernetes, AWS ECS, GCP Cloud Run), the media architecture seamlessly supports cloud object storage:

```text
ML Pipeline / Drone Ingestion
            │
            ▼
AWS S3 / GCP Cloud Storage (civicpulse-evidence-bucket)
            │
            ├──► CloudFront / Cloud CDN (Signed URL)
            ▼
Database (evidence.file_path = "https://cdn.civicpulse.org/evidence/hazard_3_LOW.jpg")
            │
            ▼
React Frontend (Direct passthrough in getEvidenceMediaUrl)
```

Because `getEvidenceMediaUrl` natively checks for `http://` and `https://` prefixes, transitioning from local static files to Amazon S3 or Google Cloud Storage buckets requires **zero frontend code changes**.
